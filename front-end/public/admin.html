New Workstation Template

Set this when the image bakes its cloud-init account name in (cloudbase-init's username=). Each lane still gets its own generated password; only the account name is fixed.
Windows images need this. cloudbase-init is pinned at bake time and can only set that account's password — name anything else and the password lands on the baked account while Guacamole signs in as a user that does not exist, which reaches the student as a plain RDP login failure. Images built from windows-11-base-packer use cactus-user; bake-win-client-template.sh uses Admin. Check the template's cloudbase-init.conf if you are unsure. Left blank on Windows, deploys fall back to cactus-user and log a warning.
On Linux, leave blank to create a per-student account from their email — cloud-init genuinely creates whatever account it is given there.
